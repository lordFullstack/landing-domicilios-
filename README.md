# Landing de Domicilios Riohacha

Página de presentación de la app. Es **HTML + CSS + JS simples** (sin build): se edita `index.html`,
`styles.css` y `main.js` y se publica sola en GitHub Pages al hacer push a `main`.

- Botones de la web: `https://domicilios-rouge.vercel.app` (`/login`, `/register?role=client|restaurant|delivery`).
- Descarga del APK: el archivo vive en `descargas/` y el botón de `#descargar` (en `index.html`) lo baja de ahí; Drive queda
  como respaldo. Para una versión nueva: copiar el APK a `descargas/`, cambiar el nombre en el botón y el texto de la versión,
  y borrar el APK anterior (cada uno pesa ~15 MB en el repositorio).
- Identidad: azul profundo `#1C2459` + degradado atardecer; fuentes Sora e Inter.
